# ประกันไปกับคุณ (insurGo) — AI Insurance Companion

**เปิดใช้งานได้ทันทีที่ → https://sarawut2206.github.io/insurGo/**

> “บอกเราว่าคุณกำลังจะไปไหน เราจะช่วยดูว่าคุณกำลังเสี่ยงอะไร
> และค้นหาความคุ้มครองที่เหมาะกับคุณ”

แพลตฟอร์ม AI วิเคราะห์ความเสี่ยงและจับคู่ความคุ้มครองประกันภัยเฉพาะบุคคล —
เราไม่ใช่บริษัทประกัน แต่เป็น **Technology Platform สำหรับบริษัทประกัน** (B2B InsurTech)

## User Journey

```
👤 ลูกค้าเล่าทริปด้วยภาษาธรรมดา
        "ผมจะพาลูก 2 คนไปเที่ยวเขาใหญ่ 2 วัน"
                    ↓
🤖 AI วิเคราะห์  →  3 คน · 2 วัน · เขาใหญ่ · ท่องเที่ยว
                    (แก้ไขได้ทุกช่อง — ระบบไม่เดาแทนโดยไม่บอก)
                    ↓
⚠️ วิเคราะห์ความเสี่ยงของทริปนี้
                    ↓
🔎 Insurance Matching — จับคู่แผนจากบริษัทพันธมิตร พร้อมเหตุผล
                    ↓
💰 ราคาตามจริง: เบี้ย × คน × วัน
                    ↓
📄 กรมธรรม์ดิจิทัล (ในต้นแบบ = ตัวอย่างจำลอง)
```

## ลองใช้

เปิด https://sarawut2206.github.io/insurGo/ แล้วพิมพ์ประโยคแบบนี้ได้เลย

- `ผมจะพาลูก 2 คนไปเที่ยวเขาใหญ่ 2 วัน`
- `บินไปญี่ปุ่น 5 วัน กับครอบครัว`
- `ไปดำน้ำที่กระบี่ 2 คน 3 วัน`
- `ขี่มอเตอร์ไซค์ไปปาย 3 วัน`

ติดตั้งเป็นแอปมือถือได้: Android (Chrome) → เมนู ⋮ → ติดตั้งแอป · iPhone (Safari) → แชร์ → เพิ่มลงในหน้าจอโฮม

รันบนเครื่องเอง: `node server.js` → เปิด `http://localhost:5173`

## สิ่งที่ระบบทำได้จริงในต้นแบบนี้

| ความสามารถ | สถานะ |
|---|---|
| เข้าใจประโยคภาษาไทย (คน วัน สถานที่ พาหนะ กิจกรรม) | ✅ rule-based NLU ทำงานในเครื่อง |
| นับ "พาลูก 2 คน" = 3 คนรวมผู้พูด | ✅ |
| บอกตรง ๆ ว่าจับข้อมูลจากคำไหน และไม่รู้อะไร | ✅ |
| วิเคราะห์ความเสี่ยงของทริป พร้อมเหตุผล | ✅ |
| จับคู่แผนจากหลายพันธมิตร เรียงตามความเหมาะสม | ✅ |
| กรองแผนที่ไม่เข้าเงื่อนไข (เช่น แผนในประเทศ กับทริปต่างประเทศ) | ✅ |
| เตือนเมื่อแผนยกเว้นกิจกรรมที่ผู้ใช้จะทำ (เช่น ดำน้ำ) | ✅ |
| คำนวณเบี้ยยืดหยุ่น: อัตรา × คน × วัน | ✅ |
| ซื้อและออกกรมธรรม์ | 🔶 จำลองทั้งหมด — มีลายน้ำ "ตัวอย่าง" กำกับ |

**ข้อมูลสมมติ:** บริษัทพันธมิตร (ก/ข/ค) แผน และเบี้ยทั้งหมดเป็นข้อมูลตัวอย่าง
ไม่ใช่ข้อเสนอจริงของบริษัทใด — ในระบบจริง ราคาและเงื่อนไขจะมาจาก API
ของบริษัทประกันโดยตรง และบริษัทเป็นผู้ออกกรมธรรม์เสมอ

**ตัววิเคราะห์ภาษา:** เวอร์ชันต้นแบบใช้ rule-based NLU ทำงานในเครื่อง 100%
(ข้อความไม่ถูกส่งออกไปที่ใด) — ระบบจริงต่อยอดเป็น LLM ได้โดยโครงสร้างเดิม

## โมเดลธุรกิจ (B2B)

บริษัทประกัน**มีผลิตภัณฑ์อยู่แล้ว** — ปัญหาคือลูกค้าไม่รู้ว่าตัวเองควรซื้ออะไร

- **Marketplace กลาง** — พันธมิตรนำผลิตภัณฑ์เข้าระบบผ่าน API เราได้ค่าธรรมเนียมต่อกรมธรรม์ที่เกิดขึ้นจริง
- **License / White-label** — บริษัทเช่าเทคโนโลยี (NLU + Risk Analysis + Matching) ไปฝังในช่องทางของตัวเอง

สิ่งที่พันธมิตรได้: ลูกค้าที่มาถึงพร้อมความต้องการชัดเจน · เข้าถึงกลุ่มที่ไม่ซื้อประกันรายปี
ด้วยความคุ้มครองแบบรายทริป · การจับคู่โปร่งใสตรวจสอบย้อนหลังได้

ดูรายละเอียดในแอป: หน้าแรก → "สำหรับบริษัทประกันภัย"

## โครงสร้างโค้ด

```
index.html       6 หน้าจอ: เล่าทริป → วิเคราะห์ → แผน → ยืนยัน → กรมธรรม์ + หน้า B2B
js/trip.js       หัวใจของระบบ: Thai NLU + Risk Analysis + Matching Engine
js/app.js        ควบคุม UI
js/store.js      เก็บข้อมูลในเครื่อง + audit log
css/styles.css   โหมดสว่าง/มืดอัตโนมัติ
manifest.json    ติดตั้งเป็นแอปได้ (PWA)
sw.js            ใช้งานออฟไลน์ได้
server.js        รันบนเครื่อง — Node ล้วน ไม่มี dependency
```

ไม่มี dependency ภายนอก ไม่มี build step ไม่เรียก CDN

## ก่อนเป็นระบบจริง

1. เชื่อม API ราคา/ผลิตภัณฑ์จากบริษัทประกันจริง แทนข้อมูลสมมติ
2. เปลี่ยน NLU เป็นโมเดลภาษา พร้อมชั้นตรวจสอบผลก่อนแสดง
3. ระบบชำระเงินและออกกรมธรรม์ โดยบริษัทผู้รับประกันเป็นผู้ออกเสมอ
4. การขายประกันภัยต้องมีใบอนุญาตนายหน้า/ตัวแทนตามกฎหมายไทย —
   แพลตฟอร์มต้องขอใบอนุญาตนายหน้าประกันวินาศภัย (แบบนิติบุคคล) ก่อนขายจริง
5. PDPA: consent, นโยบายเก็บข้อมูล, การเข้ารหัส เมื่อเริ่มมีเซิร์ฟเวอร์
