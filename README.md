# ประกันไปกับคุณ (insurGo)

**เปิดใช้งานได้ทันทีที่ → https://sarawut2206.github.io/insurGo/**

> บอกเราว่าคุณกำลังจะไปไหน เราจะช่วยดูว่าคุณกำลังเสี่ยงอะไร
> และค้นหาความคุ้มครองที่เหมาะกับทริปของคุณ

แพลตฟอร์ม InsurTech ที่วิเคราะห์ทริปจากภาษาไทยธรรมดา ประเมินความเสี่ยง
แล้วจับคู่ความคุ้มครองจากบริษัทประกันพันธมิตร

**เราไม่ใช่บริษัทประกัน — เราคือเทคโนโลยีของบริษัทประกัน**

## ใช้งานได้ 3 แบบจากโค้ดชุดเดียว

| แบบ | วิธีเข้าถึง | สถานะ |
|---|---|---|
| เว็บ | เปิดลิงก์ด้านบน | ใช้งานได้แล้ว |
| PWA ติดตั้งลงหน้าจอโฮม | เปิดลิงก์บนมือถือ → กด "ติดตั้ง" | ใช้งานได้แล้ว |
| แอปเนทีฟ (APK / IPA) | `npm run app:android` | พร้อม build |

เปิด https://sarawut2206.github.io/insurGo/ บนมือถือ แล้ว

- **Android (Chrome):** แอปจะเด้งปุ่ม "ติดตั้ง" ให้เอง หรือเมนู ⋮ → ติดตั้งแอป
- **iPhone (Safari):** ปุ่มแชร์ → เพิ่มลงในหน้าจอโฮม (แอปมีคำแนะนำในตัว)

## รันบนเครื่องตัวเอง

```bash
npm run dev
```

เปิด `http://localhost:5173` — ตอนรันจะพิมพ์ IP ในวง Wi-Fi ออกมาด้วย
ให้มือถืออยู่ Wi-Fi เดียวกันแล้วเปิดลิงก์นั้นได้เลย

**เวอร์ชันเว็บไม่มี dependency เลย** ไม่ต้อง `npm install` ไม่มี build step
โค้ดเป็น ES module มาตรฐานที่เบราว์เซอร์รันได้ตรง ๆ ไม่เรียกฟอนต์หรือสคริปต์จาก CDN
ข้อมูลผู้ใช้จึงไม่รั่วไปยังบุคคลที่สาม

## สร้างเป็นแอปมือถือจริง

ใช้ [Capacitor](https://capacitorjs.com/) ห่อโค้ดเว็บชุดเดิมเป็นแอปเนทีฟ
โดย**ไม่ต้องเขียนโค้ดใหม่** — `js/core/native.js` ตรวจเองว่ากำลังรันบนอะไร
แล้วเลือกใช้ API ของเครื่องหรือของเว็บให้อัตโนมัติ

### Android → ได้ไฟล์ APK

ต้องมี [Android Studio](https://developer.android.com/studio) ติดตั้งไว้ก่อน

```bash
npm install
npm run app:init
npm run app:android
npm run app:open:android
```

จากนั้นใน Android Studio เลือก **Build → Build Bundle(s) / APK(s) → Build APK(s)**
ได้ไฟล์ `.apk` ที่ส่งให้คนอื่นติดตั้งได้ทันที

### iOS → ได้แอปสำหรับ App Store

ต้องใช้ **macOS + Xcode** และบัญชี Apple Developer (ปีละ 99 USD)

```bash
npm install
npm run app:init
npm run app:ios
npm run app:open:ios
```

### แก้โค้ดแล้วอัปเดตแอป

```bash
npm run app:sync
```

scripts/build.js      เตรียมโฟลเดอร์ www/ สำหรับ Capacitor
server.js             เซิร์ฟเวอร์สำหรับรันบนเครื่อง

## หลักการที่ยึดไว้ในโค้ด

**อธิบายได้ทุกคำแนะนำ** — ทุกคะแนนย้อนกลับไปหากฎที่ทำให้เกิดได้
ระบบเก็บเหตุผลไว้ตอนคำนวณ ไม่ใช่หาคำอธิบายมาแปะทีหลัง

**ไม่เดาแทนผู้ใช้แบบเงียบ ๆ** — ถ้าระบบเดาให้ จะติดป้าย ✨ และเส้นประไว้เสมอ
และไม่เดากิจกรรมความเสี่ยงสูงให้ใครเด็ดขาด

**ไม่ซ่อนสิ่งที่ไม่เข้าใจ** — ปลายทางที่ไม่รู้จักจะบอกตรง ๆ
แผนที่ถูกคัดออกจะแสดงเหตุผล ไม่ใช่หายไปเฉย ๆ

**ไม่แนะนำสิ่งที่ไม่คุ้มครองสิ่งที่ผู้ใช้จะไปทำ** — แผนที่ยกเว้นกิจกรรมหลักของผู้ใช้
จะถูกลดอันดับและติดคำเตือน

**ข้อมูลอยู่ในเครื่องผู้ใช้** — ข้อความที่พิมพ์วิเคราะห์ในเครื่อง ไม่ส่งออกไปที่ใด
ไม่เก็บชื่อ เบอร์โทร หรือเลขบัตรประชาชน ผู้ใช้ดู ดาวน์โหลด และลบข้อมูลได้เอง

**AI ไม่ตัดสินแทนบริษัทประกัน** — ระบบไม่อนุมัติ ไม่ปฏิเสธ ไม่กำหนดเบี้ยจริง

## มาตรฐานที่ผ่านแล้ว

**การเข้าถึง**
- พื้นที่แตะทุกปุ่มอย่างน้อย 44px ตาม Apple HIG และ WCAG 2.5.5
- โฟกัสย้ายไปหัวข้อของหน้าใหม่ทุกครั้ง พร้อมประกาศให้โปรแกรมอ่านหน้าจอ
- ทุกหน้ามี `aria-labelledby` · แผ่นเลื่อนมี `role="dialog"` และกักโฟกัสไว้ข้างใน
- โฟกัสริงเห็นชัดเฉพาะผู้ใช้คีย์บอร์ด ไม่รบกวนผู้ใช้จอสัมผัส
- skip link · เคารพ `prefers-reduced-motion`

**ความรู้สึกแบบแอป**
- ปุ่มย้อนกลับของเครื่องทำงานถูกต้องทั้งบนเว็บและแอปเนทีฟ
- สั่นตอบสนองเมื่อแตะ ปรับระดับตามความสำคัญของการกระทำ
- ปิดดีเลย์แตะ 300ms และการเด้งของหน้าเว็บ
- รองรับ safe area ของจอมีรอยบาก
- โหมดสว่างและมืดอัตโนมัติ

## ⚠ ข้อจำกัดที่ต้องรู้

**1. บริษัทพันธมิตรและเบี้ยประกันเป็นข้อมูลสมมติทั้งหมด**
พันธมิตร ก–จ และแผนทั้ง 10 แผนถูกสร้างขึ้นเพื่อสาธิตกลไกการจับคู่เท่านั้น
ไม่ได้ใช้ชื่อบริษัทจริง เพราะการนำชื่อบริษัทที่มีตัวตนจริงมาผูกกับตัวเลขที่เราสมมติ
คือการสร้างข้อมูลเท็จเกี่ยวกับบริษัทเหล่านั้น
รายชื่อบริษัทจริงอยู่ในหน้า "บริษัทประกันภัยในไทย" โดยไม่มีราคาผูกไว้

**2. ตัวเข้าใจภาษาเป็น rule-based ไม่ใช่โมเดลภาษาขนาดใหญ่**
ข้อดีคือทำงานทันที ไม่ต้องต่อเน็ต ไม่ส่งข้อความผู้ใช้ออกนอกเครื่อง
ข้อจำกัดคือเข้าใจเฉพาะรูปประโยคที่ครอบคลุมไว้ ระบบจึงให้แก้ไขได้ทุกช่องเสมอ

**3. `js/data/plans.js` เปิดเผยต่อสาธารณะ**
เมื่อโฮสต์เป็นเว็บ static กฎและน้ำหนักทั้งหมดอ่านได้จากเบราว์เซอร์
หากต้องการเก็บสูตรเป็นความลับ ต้องย้าย `js/core/match.js` ไปเป็น API ฝั่งเซิร์ฟเวอร์

**4. ยังไม่มี API จริงของบริษัทประกัน**
การได้ API ไม่ใช่ปัญหาทางเทคนิค แต่เป็นกระบวนการด้านกฎหมายและความร่วมมือ —
ต้องมีใบอนุญาตนายหน้าประกันวินาศภัยจาก คปภ. ก่อน
รายละเอียดเส้นทางอยู่ในหน้า "สำหรับบริษัทประกันภัย" ในแอป

**5. น้ำหนักคะแนนยังไม่ผ่านการตรวจสอบเชิงคณิตศาสตร์ประกันภัย**
ตั้งจากเหตุผลเชิงตรรกะ ต้องให้ผู้เชี่ยวชาญตรวจก่อนนำไปใช้ให้คำแนะนำจริง
